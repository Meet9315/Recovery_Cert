# E21: journaled native-session authority and actual process faults

16 October 2026. Predeclared before implementation activation and fault outcomes. E20's actual native byte routes pass, but have no durable authority/recovery. Implement a separate opt-in native-session format; keep historical file-store APIs/formats and E19 timing source unchanged. ## Bounded contract

One immutable object scope/plan, 4096-byte code rows, trusted local clients, SQLite WAL/FULL authority, and a private serial supervisor owning one fresh QEMU controller session. The supervisor and QEMU survive authority actor exits. Device-session/VM loss is unsupported and fails closed; serial alone never proves continuity of a recreated session. No physical power-loss guarantee, distributed consensus, native zone append or dynamic cancellation is asserted.

Bind authority store UUID to a fresh supervisor session UUID, token, controller serial, namespace/capacity map and boot identity. The session may bind only one authority. Every command carries store/session/fence identity. A takeover barrier serially completes earlier submitted operations, advances the supervisor fence, and rejects late old-fence requests before native submission. Publish the new database fence only after the barrier returns; a failed transition must remain conservative.

Validate/admit the complete finite witness and authenticate LIVE code rows. Journal identity-bound intent for native open/close/finish/stage/reset acknowledgement before physical action. Bind store/session/cursor/pre-state/action/incarnation and stage epoch/row digest. During I/O retain the SQLite transaction/source state, recheck authority and supervisor fences, reconcile authoritative report states, authenticate complete append adoption and atomically publish receipt/state/cursor. Split stage writes into two aligned 2048-byte native writes to expose a real partial-append boundary. Partial/unexplained native outcomes quarantine without rewind/reset or false capacity credit. Duplicate completed cursors return receipts without reissuing physical commands.

Maintain a distinct incomplete-bootstrap marker; never resume/reuse an interrupted creation. No plaintext fallback is persisted. Native FULL/FINISHED pointer sentinels are interpreted with capacity/condition and explicit state, never as zero/free capacity. Pending or unknown outcomes report no appendable credit. The supervisor's private diagnostic delay/stats controls are experiment facilities, not an exposed storage product API.
